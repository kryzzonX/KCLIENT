# K Client (Fabric, Minecraft 1.21.4)

Right Shift opens the K Client click GUI (HUD / PvP / Crosshair / Settings).
HUD: FPS, CPS, ping, combo, coordinates, direction, clock, armor HUD, potion HUD, item counter, keystrokes.
PvP: toggle sprint, zoom (C). Custom crosshair with live preview. No hacks.
